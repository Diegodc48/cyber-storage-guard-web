Seguridad por diseño

Primero entender.
Después decidir.

No queremos que un clic impulsivo se lleve por delante un proyecto importante. La herramienta está concebida para observar, explicar y advertir, sin ejecutar limpiezas automáticas.

  • Sin eliminación automática de archivos ni carpetas.
  • Rutas protegidas y avisos cuando una recomendación no es segura.
  • Datos locales, con carpeta de almacenamiento configurable.
  • Sin traslado silencioso de los datos de la aplicación a C:.
  • Sin inicio automático con Windows en la versión de prueba actual.

Estas características describen el estado de desarrollo documentado; la edición pública deberá superar pruebas adicionales.

Preguntas frecuentes

Todo claro desde el principio.

Respuestas breves sobre la futura publicación.

¿CYBER STORAGE GUARD será gratuito?

Sí. Está prevista una distribución gratuita (freeware) para Windows.

¿Se publicará el código fuente?

No. La intención es distribuir el programa compilado y conservar el código fuente privado.

¿Puede borrar mis archivos?

El diseño actual se basa en vigilancia, análisis y recomendaciones; no realiza limpiezas automáticas. Cualquier futura función de limpieza requeriría un diseño y autorización explícitos.

¿Ya puedo descargarlo?

Todavía no. La aplicación sigue en pruebas y la descarga oficial se habilitará únicamente cuando se valide una versión pública.

¿Funciona en cualquier ordenador?

Está desarrollándose para Windows 10 y 11. La compatibilidad en distintos equipos deberá validarse antes del lanzamiento.

¿La web necesita conexión a Internet para abrirse?

Esta web funciona localmente: basta con extraer el ZIP y abrir index.html. No utiliza bibliotecas ni imágenes externas.
